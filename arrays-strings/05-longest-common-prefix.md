## Problem: Longest Common Prefix (Easy–Medium)

**Link:** [Longest Common Prefix](https://leetcode.com/problems/longest-common-prefix/)

### Approach
Start with the first string as the prefix and shorten it until every string starts with it.

### Complexity
- Time: O(S)
- Space: O(1)

### Notes
Return an empty string when there is no common prefix.
